# Мотор + серво + червоний LED: три автономні прошивки

Оберіть ОДНУ папку під свою плату. Усі файли .h залишайте поруч з відповідним .ino.
Попередні прошивки 01–08 не замінені.

| Плата | Папка / файл .ino |
|---|---|
| NodeMCU v3 (ESP8266) | 09_NodeMCU_MotorServoLED/09_NodeMCU_MotorServoLED.ino |
| Wemos D1 mini Pro (ESP8266) | 10_WemosPro_MotorServoLED/10_WemosPro_MotorServoLED.ino |
| ESP32-S3 N16R8 DevKitC-1 | 11_ESP32S3_MotorServoLED/11_ESP32S3_MotorServoLED.ino |

У репозиторії папки знаходяться всередині ArduinoIDE. В архіві вони лежать поряд із цією інструкцією.
Кожна плата самостійно створює сайт і керує своїми приводами: ESP-NOW, іншої плати та роутера немає.

## Підключення

| Призначення | NodeMCU v3 (09) | Wemos D1 mini Pro (10) | ESP32-S3 (11) |
|---|---|---|---|
| L298N ENA | D1 / GPIO5 | D1 / GPIO5 | GPIO5 |
| L298N IN1 | D2 / GPIO4 | D2 / GPIO4 | GPIO6 |
| L298N IN2 | D5 / GPIO14 | D6 / GPIO12 | GPIO7 |
| Серво, жовтий сигнал | D6 / GPIO12 | D5 / GPIO14 | GPIO15 |
| RGB-модуль, контакт R | D7 / GPIO13 | D7 / GPIO13 | GPIO4 |
| GND | Спільна земля | Спільна земля | Спільна земля |

На ESP32 це номери GPIO, НЕ порядкові номери ніжок. Звірте шовкографію саме вашої 44-pin плати-клона.
Обрані GPIO4/5/6/7/15 виведені на стандартному DevKitC-1 та не займають USB, UART0 або лінії flash/PSRAM.
[Карта Espressif](https://docs.espressif.com/projects/esp-idf/en/v4.4.3/esp32s3/hw-reference/esp32s3/user-guide-devkitc-1.html).

### RGB-модуль використовується тільки як червоний LED

- R → GPIO за таблицею.
- Спільний **GND модуля** → GND ESP.
- G і B залишити вільними. Не з'єднувати R/G/B разом.
- У червоній гілці обов'язково має бути послідовний резистор **250 Ом**, як ви зазначили. Якщо його немає на платі — встановити зовнішній.
- Окремі 5 В до RGB-модуля **не підключати**. LED живиться від GPIO 3,3 В.
- Схема лише для підтвердженого спільного мінуса. Якщо четвертий контакт є спільним анодом/плюсом, ця схема непридатна.
- Для більш потужного світла потрібен транзистор; цей GPIO не є силовим виходом 5 В.

### L298N та серво

- Зняти перемичку ENA. Додати 10 кОм ENA → GND, щоб міст був вимкнений під час reset/прошивання.
- D1/ENA не під'єднувати до ENB; використовується тільки канал A, OUT1/OUT2.
- Допускається ваша схема двох DC-моторів паралельно на одному мосту лише в межах сумарного пускового струму драйвера.
- Серво: червоний → стабільні 5 В відповідно до паспорта; коричневий → спільний GND.
- Живлення серво не брати з 3V3 ESP. Модуль L298N не вважати автоматично достатнім джерелом 5 В для серво та ESP.
- Для ESP: NodeMCU VIN / Wemos 5V / ESP32-S3 5V — лише коректні стабілізовані 5 В із перевіркою схеми конкретної плати.
- Не подавати 5 В на жоден GPIO.
- Під час USB-прошивання від'єднати силове живлення приводів і зовнішню подачу 5 В на ESP, щоб уникнути конфлікту джерел.

## Arduino IDE

Бібліотеки для всіх трьох:
- WebSockets by Markus Sattler, 2.7.3.
- ArduinoJson by Benoit Blanchon, 7.4.3.

Wi-Fi, вебсервер, DNS, mDNS та генератори PWM входять у пакет плати. Окрема бібліотека Servo/ESP32Servo не потрібна.

Для 09/10:
- Пакет ESP8266 Community 3.1.2.
- 09: Board → NodeMCU 1.0 (ESP-12E Module).
- 10: Board → LOLIN(WEMOS) D1 mini Pro.
- CPU 80 MHz; Upload Speed 115200.
- URL: https://arduino.esp8266.com/stable/package_esp8266com_index.json

Для 11:
- Пакет esp32 by Espressif Systems **3.3.3** (код використовує LEDC API 3.x; не 2.x).
- URL: https://espressif.github.io/arduino-esp32/package_esp32_index.json
- Board → **ESP32S3 Dev Module**.
- Flash Size → **16MB (128Mb)**.
- PSRAM → **OPI PSRAM** для вашої N16R8.
- Flash Mode → QIO 80MHz; Partition Scheme → 16M Flash (3MB APP/9.9MB FATFS).
- Upload Speed → 115200 для першого тесту.
- Для першого прошивання використовуйте роз'єм USB-UART; USB CDC On Boot → Disabled.
- Якщо користуєтесь native USB, а не USB-UART: USB Mode → Hardware CDC and JTAG, USB CDC On Boot → Enabled; після reset може змінитися COM-порт. Піни USB19/20 код не використовує.
- Для плати з IPEX під'єднайте відповідну антену 2,4 GHz. Наявність зовнішнього роз'єму не доводить, що ваш клон має активну внутрішню антену.

Розпакуйте архів у доступну для запису папку, бажано латиницею. Відкрийте .ino саме потрібної папки та прошийте. Не додавайте три .ino вкладками в один скетч.
Serial Monitor — **115200 baud**; на ESP32 USB-UART це UART0, а при ввімкненому CDC — USB Serial.

## Сайт

Wi-Fi: **Motor-Control**, пароль **motor8266**.
Адреса: **http://192.168.4.1**, також http://motor.local за наявності mDNS.

Збережені слайдер, швидкість 1–100% (старт 50%), ручні Вліво/Вправо, центр, Маятник/Драбинка/Ривки/Рандом, серво45°/90° та STOP.
Під час фактичної подачі PWM на мотор червоний LED автоматично працює як стробоскоп: 125 мс увімкнений і 125 мс вимкнений, тобто 4 повні спалахи за секунду. Строб має пріоритет над ручним станом світла. Після STOP він одразу припиняється, а LED повертається до стану, заданого кнопкою **Світло: увімкнено / вимкнено**. Усі підключені телефони бачать спільний стан і напис **Світло: строб** під час руху.
При перезапуску LED вимкнений; стан не записується у flash. Без енкодера прошивка визначає рух за ненульовим PWM: якщо мотор заблокований механічно, але драйвер отримує PWM, LED все одно стробить; вільний вибіг після вимкнення PWM не визначається.
Серво починає роботу лише після запуску програми, відкриту позицію утримує 1 с, закриту 2 с; переміщення поступове. Для цього механізму 45° на сайті передається як команда 90°, а 90° на сайті — як команда 180°; сайт і статус показують фізичний кут.
У config.h залишені попередні 333 Hz / 520–2520 мкс: перевірте відповідність паспорту вашого серво, не допускайте механічних упорів.

SPEED_CALIBRATION у config.h містить приклад, не виміри. Без енкодера координата розрахункова; після ручного руху заново виставляйте центр.
Жодна успішна компіляція не гарантує відсутність проблем живлення/пайки. Перший запуск — без силового живлення приводів, потім по одному компоненту.

Якщо кілька плат увімкнені поруч, змініть WIFI_SSID у кожній папці на різні назви — інакше важко зрозуміти, до якої ви під'єдналися.

## Для розробника

Канонічні джерела нових версій — standalone-led/. Вони не містять ESP-NOW.
Копії оновлює scripts/sync-standalone-led.ps1; перевіряє scripts/sync-standalone-led.ps1 -Check.
Синхронізація перезаписує config.h у 09/10/11 — спочатку збережіть власні калібрувальні виміри.
Мотор і серво на ESP32 використовують різні частоти/роздільності LEDC; частота серво не змінює PWM мотора.
[Офіційний LEDC API](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/ledc.html).
