# Бігунок — ESP8266, L298N та сервопривід

**Нові окремі автономні варіанти мотор + серво + червоний LED для NodeMCU, Wemos Pro та ESP32-S3: [інструкція 09/10/11](README_STANDALONE_LED.md).**

Окремі Arduino-скетчі для NodeMCU v3 та Wemos D1 mini Pro, двоплатного ESP-NOW, калібрування і тестів. **Основна інструкція для пайки та прошивання: [ArduinoIDE/README.md](ArduinoIDE/README.md).**

Це прототип без енкодера: координата розрахункова, а не виміряна. Жодна прошивка не гарантує відсутності перезапусків при неправильному живленні, пайці або несправній платі.

## Підключення — актуальна версія

| Сигнал | 03: NodeMCU v3 + серво | 07: Wemos D1 mini Pro + серво | 02 / 04 / 05: стандартний мотор |
|---|---|---|---|
| ENA | D1 / GPIO5 | D1 / GPIO5 | D1 / GPIO5 |
| IN1 | D2 / GPIO4 | D2 / GPIO4 | D2 / GPIO4 |
| IN2 | D5 / GPIO14 | D6 / GPIO12 | D5 / GPIO14 |
| Серво, жовтий | D6 / GPIO12 | D5 / GPIO14 | не використовується |

Для `06_TwoMotors_OneESP`: D1 → ENA+ENB; D2 → IN1; D5 → IN2; D6 → IN3; D7 → IN4. Серво немає. Обидва мости отримують однакові PWM і напрямок; це **не гарантує однакових обертів** двох різних двигунів.

Старі версії 02/04/05 використовували D6/D7/D8 — перед новою прошивкою перепідключіть їх за таблицею. Старе зображення `docs/wiring-two-variants.png` залишене як архів і **не є актуальною схемою пайки**.

D3/GPIO0, D4/GPIO2, D8/GPIO15, RX/TX, RST та EN у цих схемах залишаються вільними від периферії. Карта GPIO звірена з [Wemos](https://www.wemos.cc/en/latest/d1/d1_mini_pro.html), вимоги старту — з [Espressif](https://docs.espressif.com/projects/esptool/en/latest/esp8266/advanced-topics/boot-mode-selection.html).

## Сайт і керування

- Wi-Fi: **Motor-Control**, пароль **motor8266**.
- Адреса: **http://192.168.4.1**; також **http://motor.local**, якщо телефон підтримує mDNS.
- Швидкість при старті 50%, користувач змінює її в діапазоні 1–100%. «СТОП» — PWM 0.
- «Вліво»/«Вправо» використовують вибраний PWM напряму, без різних коефіцієнтів для напрямків.
- Маятник, Драбинка, Ривки, Рандом змінюють точки маршруту, не скидають користувацьку швидкість.
- Серво у 03/07: плавні кроки 1° кожні 20 мс; відкрита позиція 45°/90° утримується 1 с, закрита — 0,5 с. Після ввімкнення живлення сигнал серво не запускається до команди програми. «СТОП»/«Вимк.» задають закриту позицію. Відображені градуси — команда, не датчик кута.
- Всі користувачі отримують спільний стан. Остання команда руху визначає керуючу вкладку; інша людина завжди може натиснути «СТОП».
- «Мотор онлайн» означає готовність контролера/радіозв'язок, а не підтвердження фізичного обертання. Датчика обертів у цій схемі немає.
- Закриття/приховування керуючої вкладки зупиняє рух; за відсутності її heartbeat спрацьовує тайм-аут 2 с. Ручний рух має окремий тайм-аут 650 мс. Вкладки-спостерігачі не підтримують чужий рух своїм heartbeat.
- Стоп одразу вимикає PWM, але механізм може рухатися за інерцією: це не механічне гальмо.

## Дві ESP8266

01 — сайт, Wi-Fi AP+STA; 02 — моторна ESP у STA. Роутер не потрібний.
ESP-NOW без шифрування, канал 6. Автопошук broadcast → спарювання за MAC, без ручного введення адрес.
Жива пара не перемикається на інший мотор; для свідомого повторного спарювання перезапустіть обидві плати. Кілька однакових комплектів поруч можуть спаруватися неправильно при старті: ця версія розрахована на один комплект.

Команди/heartbeat передаються кожні 20 мс, змінений STOP — без очікування цього інтервалу.
Статус мотора — кожні 100 мс; стан сайту — кожні 50 мс, якщо є клієнти.
Мотор вимикає PWM після 500 мс без команд; контролер також зупиняє програму при втраті статусу.
Це програмні тайм-аути, не апаратний аварійний захист і не гарантія максимальної радіозатримки.
25–40 м потрібно перевіряти на конкретному комплекті та місці.

## Калібрування та довжина

У `config.h` потрібного скетчу:
- `TRACK_LENGTH_M = 4.0f`: загальна довжина; центр 0, кінці ±2 м.
- `SAFE_MARGIN_M = 0.20f`: програмна зона ±1,8 м.
- `SPEED_CALIBRATION`: **приклади**, замініть власними вимірами.
- Таблиця містить PWM, швидкість вправо, швидкість вліво у м/с.
- Для 01 таблиця потрібна на контролері; для 03/06/07 — у відповідній папці.

04 створює `Motor-Calibration`, пароль `motor8266`.
Задайте PWM 0–100%, напрямок, тривалість. Після завершення виміряйте відстань рулеткою й введіть її на сайті.
Сторінка використовує фактичну тривалість увімкнення, повідомлену ESP, та не приймає перерваний тест.
Нульова відстань допустима. Формула: `метри за секунду = сантиметри / 100 / секунди`.

Плавний розгін входить у час тесту, тому короткий тест дає **середню швидкість від старту**, а не точну усталену швидкість. Повторюйте вимірювання; для усталеної швидкості вимірюйте відрізок після розгону. Інерція, прослизання і батарея впливають на результат.
Після ручного переміщення встановіть механізм у фізичний центр та натисніть «Позначити поточне місце як центр». Ручні кнопки не вимірюють координату.

Для реальних обмежень ходу потрібні кінцевики й/або енкодер. Програмний запас біля кінців не запобігає зіткненню при помилці калібрування.

## Структура для розробника

- `src/main.cpp` — єдина актуальна реалізація сайту/ESP-NOW/моторів/серво.
- `src/calibration.cpp` — калібрування.
- `include/config.h`, `include/motor_output.h`, `include/web_ui.h` — конфігурація, спільний вихід L298N, сайт.
- Кожна папка Arduino — самодостатня копія; 07 більше не включає файли з 03.
- `web-interface-demo.html` — лише автономний візуальний симулятор, не керує ESP і не заміняє тест обладнання.

Після редагування канонічних `src/` та `include/`:
```powershell
./scripts/sync-arduino.ps1
./scripts/sync-arduino.ps1 -Check
node tests/ui.test.cjs
./scripts/build-arduino.ps1
```
Синхронізація **перезаписує** локальні конфігурації Arduino-копій: спочатку перенесіть свої виміри в канонічну конфігурацію або збережіть їх окремо.
Для бібліотек поза стандартною папкою використовуйте `-LibraryRoot C:/Arduino/libraries`.

PlatformIO: `controller`, `motor`, `single` (NodeMCU), `single_wemos`, `dual`, `calibration`.
Наприклад, `pio run -e single_wemos` компілює; додавання `-t upload` прошиває. Не завантажуйте прошивку автоматично під час механічного тесту.
