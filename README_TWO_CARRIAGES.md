# Дві каретки: ESP32 + NodeMCU

Ця версія знаходиться на гілці `two-carriages` і не змінює `main`.

## Що прошивати

1. `ArduinoIDE/12_TwoCarriages_ESP32_Controller/` — ESP32-S3, перша каретка та сайт.
2. `ArduinoIDE/13_TwoCarriages_NodeMCU/` — NodeMCU v3, друга каретка.

Телефон підключається лише до Wi-Fi ESP32:

- мережа: `Motor-Control`
- пароль: `motor8266`
- адреса сайту: `http://192.168.4.1`

NodeMCU автоматично підключається до цієї ж мережі і надсилає ESP32 свій статус. MAC-адреси та IP другої каретки вручну вводити не потрібно: ESP32 запам'ятовує адресу пакета статусу.

## Піни

### Перша каретка, ESP32-S3 + L298N

- GPIO4 → ENA, без перемички ENA.
- GPIO5 → IN1.
- GPIO6 → IN2.
- Спільний GND ESP32, L298N і джерела живлення обов'язковий.

### Друга каретка, NodeMCU v3 + L298N

- D1 / GPIO5 → ENA, без перемички ENA.
- D2 / GPIO4 → IN1.
- D5 / GPIO14 → IN2.
- GND NodeMCU → GND L298N.

Не підключайте моторний міст до 3.3 V плати. Живлення двигуна — окремо відповідно до вашого L298N та двигуна.

## Як це працює

- ESP32 створює Wi-Fi AP і тримає сайт з WebSocket: усі телефони бачать спільний стан.
- ESP32 керує мотором каретки 1 напряму.
- ESP32 надсилає UDP-команду каретці 2 кожні 50 мс.
- NodeMCU вимикає мотор через 700 мс без команд.
- Якщо вимкнути синхронізацію кнопкою ланцюжка, команди й програми стосуються тільки вибраної каретки.
- Кнопки 45°/серво з попередньої одноплатної версії тут не використовуються.

Координата на мішені поки що розрахункова — її потрібно окремо калібрувати під механіку або замінити на енкодер/кінцевики. Перед першим механічним запуском перевірте напрямок, низьку швидкість та аварійний STOP.
