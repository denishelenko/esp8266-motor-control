# Фізичне калібрування двох кареток ESP32-S3

Поточна версія `main` використовує попередній сайт і ESP-NOW між двома ESP32-S3. Сайт показує **розрахункову**, а не виміряну датчиком позицію. Нулі в `TRAVEL_TIMES` означають, що реальний час проходження 16 м ще не введений.

## Що прошити

- Головна каретка з сайтом: `Arduino IDE/2_Carriages_WebSite/ESP32S3_Controller_Carriage_1/ESP32S3_Controller_Carriage_1.ino` або профіль PlatformIO `dual_esp32s3_controller`.
- Друга каретка: `Arduino IDE/2_Carriages_WebSite/ESP32S3_Carriage_2/ESP32S3_Carriage_2.ino` або профіль `dual_esp32s3_remote`.
- Для роботи через зовнішню мережу Motor-Control замість власної точки доступу є відповідні версії в `Home dev internet/2_Carriages_WebSite` та профілі `dual_home_main_serial`, `dual_home_remote_serial`.

## Як заміряти

1. Поставте каретку на безпечній прямій ділянці з достатнім запасом для обраного часу руху. Два метри на кожному кінці 20-метрового троса лишають 16 м робочої зони, але це **не фізичний кінцевик**.
2. Під’єднайте телефон до Wi-Fi головної ESP32, відкрийте її сайт. Виберіть каретку. Для другої переконайтеся, що на сайті вона онлайн.
3. Встановіть швидкість повзунком, розгорніть «Ручне калібрування», виберіть напрямок і натисніть 1 с, 2 с або 5 с. Тест запускає **лише вибрану** каретку, навіть якщо раніше було увімкнено синхронізацію.
4. Виміряйте рулеткою фактично пройдену відстань. Повторіть для протилежного напрямку і кількох значень швидкості, особливо там, де мотор щойно починає рухатись.
5. Кнопка СТОП перериває тест. Під час калібрування тримайте телефон поруч і залишайте вільний простір перед кареткою.

| Каретка | Швидкість % | Напрямок | 1 с, м | 2 с, м | 5 с, м |
| --- | ---: | --- | ---: | ---: | ---: |
| 1 | 50 | вправо | | | |
| 1 | 50 | вліво | | | |
| 2 | 50 | вправо | | | |
| 2 | 50 | вліво | | | |

Запишіть також стартову точку й відмітьте, чи мотор почав крутитись одразу. Прискорення, плавний старт PWM і затримка радіозв’язку впливають на короткі тести; не вважайте відстань за 1 с точною постійною швидкістю. Після вимірювань внесемо реальні значення у модель руху. До цього цифри метрів на сайті залишаються приблизними.
