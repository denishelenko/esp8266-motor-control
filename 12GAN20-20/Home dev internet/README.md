# Home dev internet

Ця папка призначена для локальних налаштувань підключення ESP до домашньої Wi‑Fi мережі.

Локальний файл `home_wifi.local.h` містить назву мережі та пароль. Він навмисно виключений із Git через `.gitignore`, щоб пароль не потрапив у публічний репозиторій.

Налаштування зберігаються тільки у локальному файлі `home_wifi.local.h` і не публікуються в репозиторії.

Однокареткові прошивки автоматично підхоплюють `home_wifi.local.h`, якщо він лежить у цій папці. Після прошивки ESP підключається до домашнього роутера. Домашню IP-адресу дивіться в Serial Monitor або у списку клієнтів роутера. Якщо mDNS підтримується мережею, сайт буде доступний за адресою `http://motor.local/`.

Готова копія скетчу NodeMCU для Arduino IDE знаходиться у папці `NodeMCU`. Відкривайте файл `NodeMCU/NodeMCU.ino`; він автоматично використовує `../home_wifi.local.h`.

Ця копія NodeMCU відрізняється від основної прошивки: вона працює тільки в режимі `STA`, тобто не створює мережу `Motor-Control` і підключається лише до домашнього Wi‑Fi.

Якщо локального файла немає, прошивка працює лише через власну точку доступу `Motor-Control` — це безпечний режим за замовчуванням.

Не публікуйте `home_wifi.local.h` і не використовуйте цей пароль у відкритому репозиторії.
