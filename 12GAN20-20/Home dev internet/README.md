# Home dev internet

Ця папка призначена для локальних налаштувань підключення ESP до домашньої Wi‑Fi мережі.

Локальний файл `home_wifi.local.h` містить назву мережі та пароль. Він навмисно виключений із Git через `.gitignore`, щоб пароль не потрапив у публічний репозиторій.

Налаштування:

```text
Wi‑Fi SSID: A8S2
Пароль: Q14Everest
```

Поточні однокареткові прошивки запускають власну точку доступу `Motor-Control`. Цей файл є підготовленим профілем домашньої мережі; щоб працювати саме через домашній роутер, прошивку потрібно зібрати в режимі STA або AP+STA. Після підключення адреса ESP видається домашнім роутером, тому її потрібно подивитися в Serial Monitor або в списку клієнтів роутера. Якщо mDNS підтримується мережею, сайт буде доступний за іменем `http://motor-control.local/`.

Не публікуйте `home_wifi.local.h` і не використовуйте цей пароль у відкритому репозиторії.
