# Головна каретка ESP32-S3, Home та OTA

Відкрийте `ESP32S3_Controller_Carriage_1.ino` в Arduino IDE. Ця версія створює сайт на головній каретці, приєднується до **зовнішньої** мережі `Motor-Control` і передає команди другій каретці через ESP-NOW. Власну точку доступу вона не створює.

Мережа і пароль, OTA пароль та канал налаштовуються у `config.h`. Точка доступу має працювати на 2,4 ГГц, **канал 6**, і дозволяти обмін між клієнтами. Адреса сайта після підключення: `http://motor.local/` або IP-адреса, надрукована в Serial Monitor на 115200 бод. Для OTA використовується ця ж IP-адреса, порт 3232.

Перше прошивання робіть через USB. У Arduino IDE виберіть ESP32S3 Dev Module, Flash Size 16 MB, PSRAM OPI та **Partition Scheme: Custom**. Файл `partitions.csv` у цій папці задає два OTA слоти у 16 МБ flash. Якщо поточна прошивка не містить OTA, оновлення через мережу не спрацює. PlatformIO пропонує профілі `dual_home_main_serial` для першого прошивання і `dual_home_main_ota` для наступних. Для OTA обидва пристрої і комп'ютер мають бути в одній мережі.

Перед записом OTA локальний мотор і сервопривід зупиняються; другій каретці надсилається стоп-команда. Її власний тайм-аут 700 мс зупинить мотор, навіть якщо команда не дійде. Якщо OTA завершиться помилкою, рух залишається заблокованим до перезапуску.
