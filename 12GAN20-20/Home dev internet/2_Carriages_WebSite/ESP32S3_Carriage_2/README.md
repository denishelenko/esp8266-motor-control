# Друга каретка ESP32-S3, Home та OTA

Відкрийте `ESP32S3_Carriage_2.ino` в Arduino IDE. Каретка приєднується до **зовнішньої** мережі `Motor-Control` для OTA, але виконує команди головної каретки через ESP-NOW і надсилає статус назад. Власного сайта або точки доступу вона не створює.

Мережа і пароль, OTA пароль та канал налаштовуються у `config.h`. Зовнішня точка доступу має бути 2,4 ГГц, **канал 6**. OTA-ім'я другої плати: `motor-carriage-2.local`. Її IP-адреса друкується в Serial Monitor на 115200 бод. Перше прошивання робіть через USB, вибравши ESP32S3 Dev Module, 16 MB flash, OPI PSRAM та **Partition Scheme: Custom**. Локальний `partitions.csv` задає два OTA слоти. PlatformIO використовує `dual_home_remote_serial`, а потім `dual_home_remote_ota`.

На початку OTA мотор і сервопривід негайно зупиняються. Якщо звичайні команди ESP-NOW не надходять понад 700 мс, мотор зупиняється автоматично. Після помилки OTA рух залишається заблокованим до перезапуску.
