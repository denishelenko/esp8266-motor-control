# NodeMCU: однокареткова прошивка для домашнього Wi‑Fi

Це готова окрема копія скетчу для NodeMCU v3. Усі файли для Arduino IDE знаходяться в цій папці.

1. Відкрийте `NodeMCU.ino` саме з цієї папки.
2. В Arduino IDE виберіть `NodeMCU 1.0 (ESP-12E Module)`.
3. Виберіть правильний COM-порт і прошийте плату.
4. Відкрийте Serial Monitor на швидкості `115200`.

Конфігурація автоматично підхоплює файл `../home_wifi.local.h` з папки `Home dev internet`. У цьому локальному файлі вказані домашня мережа та пароль; сам файл не додається до Git.

Після запуску NodeMCU підключається тільки до домашнього Wi‑Fi, без створення мережі `Motor-Control`. У Serial Monitor з’явиться IP-адреса. Телефон потрібно підключити до тієї самої домашньої мережі, а сайт відкрити за цією IP-адресою.

Підключення каретки, двигунів, сервоприводу та RGB-індикатора не змінюється:

```text
D1 → ENA L298N
D2 → IN1 L298N
D5 → IN2 L298N
D6 → сигнал сервоприводу через TXS0108E
D0 → R RGB (червоний)
D7 → G RGB (зелений)
```
