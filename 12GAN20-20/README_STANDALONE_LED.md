# Мотор + серво + RGB LED: три автономні прошивки

Оберіть ОДНУ папку під свою плату. Усі файли .h залишайте поруч з відповідним .ino.
Для поточної розводки з двома мостами відкрийте скетч ESP32-S3. NodeMCU та Wemos залишені для попередніх збірок.

| Плата | Папка / файл .ino |
|---|---|
| NodeMCU v3 (ESP8266) | `1_Carriage_WebSite/NodeMCU/NodeMCU.ino` |
| Wemos D1 mini Pro (ESP8266) | `1_Carriage_WebSite/Wemos/Wemos.ino` |
| ESP32-S3 N16R8 DevKitC-1 | `1_Carriage_WebSite/ESP32S3/ESP32S3.ino` |

Усі три папки знаходяться всередині [Arduino IDE](<Arduino IDE>) і є самодостатніми скетчами.
Кожна плата самостійно створює сайт і керує своїми приводами. Звичайні скетчі працюють через власну точку `Motor-Control`; окремий скетч для домашнього Wi‑Fi знаходиться у `Home dev internet/NodeMCU`.

У розділі «Ручне калібрування» є тест часу на 1, 2, 3 та 4 секунди. Встановіть каретку приблизно в центрі, виберіть напрямок і натисніть потрібний час. Після автоматичної зупинки виміряйте рулеткою фактичну відстань. Запишіть результати у `TIME_CALIBRATION` у `config.h` відповідного скетчу: там зберігаються секунди, швидкість тесту та окремі значення для руху вправо і вліво. Цей тест не визначає положення датчиком: координата залишається розрахунковою.

## Підключення

| Призначення | NodeMCU v3 | Wemos D1 mini Pro | ESP32-S3 |
|---|---|---|---|
| ENA | Перемичка на L298N | D1 / GPIO5, PWM | Без окремого піна |
| IN1 | D1 / GPIO5, PWM | D2 / GPIO4 | GPIO1 → A1A і B1A |
| IN2 | D2 / GPIO4, PWM | D6 / GPIO12 | GPIO2 → A1B і B1B |
| Серво, жовтий сигнал | D5 / GPIO14 | D5 / GPIO14 | GPIO42 → A1 TXS0108E, B1 → жовтий |
| RGB-модуль, контакт R (червоний) | D0 / GPIO16 | D0 / GPIO16 | GPIO47 |
| RGB-модуль, контакт G (зелений) | D7 / GPIO13 | D7 / GPIO13 | GPIO21 |
| GND | Спільна земля | Спільна земля | Спільна земля |

На ESP32 це номери GPIO, НЕ порядкові номери ніжок. Звірте шовкографію саме вашої 44-pin плати-клона.
Обрані GPIO1/2/42/47/21 виведені на стандартному DevKitC-1; GPIO42 не використовуйте одночасно для зовнішнього JTAG.
[Карта Espressif](https://docs.espressif.com/projects/esp-idf/en/v4.4.3/esp32s3/hw-reference/esp32s3/user-guide-devkitc-1.html).

### Червоний і зелений канали RGB-модуля використовуються як автоматичний індикатор

- R → відповідний GPIO за таблицею. G → відповідний GPIO за таблицею. B залишити вільним.
- Спільний **GND модуля** → GND ESP.
- У кожній кольоровій гілці має бути власний послідовний резистор **250–1000 Ом**. Якщо на модулі немає окремого резистора для R і G — встановити їх зовні.
- Окремі 5 В до RGB-модуля **не підключати**. LED живиться від GPIO 3,3 В.
- Схема лише для підтвердженого спільного мінуса. Якщо четвертий контакт є спільним анодом/плюсом, ця схема непридатна.
- Для більш потужного світла потрібен транзистор; цей GPIO не є силовим виходом 5 В.

### ESP32-S3 з двома мостами

- Мотор 1 → виходи моста A. Мотор 2 → виходи моста B. Розгалужуються лише входи керування.
- PWM подається на `1` або `2`, другий вхід на LOW. У стані стоп обидва входи LOW. Окремого піна ENA у скетчі немає.
- Для 12 В потрібен драйвер із підтвердженим допуском 12 В, підтримкою входів 3,3 В і запасом на пусковий струм кожного мотора. UMW L9110S на 12 В не розрахований.
- `3V3` ESP32-S3 → `VA` TXS0108E, перемичка `VA–OE`, `5V` → `VB`, земля спільна. Жовтий провід серво йде на `B1`, червоний отримує 5 В напряму від понижувача, коричневий йде на GND.
- `MOTOR_DIRECTION_REVERSED` у `config.h` змінює напрямок обох моторів. Якщо лише один мотор обертається проти потрібного напряму, поміняйте місцями два його вихідні проводи.

### L298N та серво в попередніх збірках NodeMCU і Wemos

- NodeMCU подає PWM на активний IN1 або IN2. Залиште перемичку ENA на L298N.
- Wemos подає PWM через D1 на ENA. Перед підключенням D1 зніміть перемичку ENA на L298N.
- Використовується тільки канал A, OUT1/OUT2. ENB до ESP не під'єднувати.
- Допускається ваша схема двох DC-моторів паралельно на одному мосту лише в межах сумарного пускового струму драйвера.
- Серво: червоний → стабільні 5 В відповідно до паспорта; коричневий → спільний GND.
- Живлення серво не брати з 3V3 ESP. Модуль L298N не вважати автоматично достатнім джерелом 5 В для серво та ESP.
- Для ESP: NodeMCU VIN / Wemos 5V / ESP32-S3 5V — лише коректні стабілізовані 5 В із перевіркою схеми конкретної плати.
- Не подавати 5 В на жоден GPIO.
- Під час USB-прошивання від'єднати силове живлення приводів і зовнішню подачу 5 В на ESP, щоб уникнути конфлікту джерел.

Для 11:
- Пакет esp32 by Espressif Systems **3.3.3** (код використовує LEDC API 3.x; не 2.x).
- URL: https://espressif.github.io/arduino-esp32/package_esp32_index.json
- Board → **ESP32S3 Dev Module**.
- Flash Size → **16MB (128Mb)**.
- PSRAM → **OPI PSRAM** для вашої N16R8.
- Flash Mode → QIO 80MHz; Partition Scheme → 16M Flash (3MB APP/9.9MB FATFS).
- Upload Speed → 115200 для першого тесту.
- Для першого прошивання використовуйте роз'єм USB-UART; USB CDC On Boot → Disabled.
- Якщо користуєтесь native USB, а не USB-UART: USB Mode → Hardware CDC and JTAG, USB CDC On Boot → Enabled; після reset може змінитися COM-порт. Піни USB19/20 код не використовує.
- Для плати з IPEX під'єднайте відповідну антену 2,4 GHz. Наявність зовнішнього роз'єму не доводить, що ваш клон має активну внутрішню антену.

Розпакуйте архів у доступну для запису папку, бажано латиницею. Відкрийте .ino саме потрібної папки та прошийте. Не додавайте три .ino вкладками в один скетч.
Serial Monitor — **115200 baud**; на ESP32 USB-UART це UART0, а при ввімкненому CDC — USB Serial.

## Сайт

Wi-Fi AP: **Motor-Control**, пароль **motor8266**.
Адреса AP: **http://192.168.4.1**, також http://motor.local за наявності mDNS. Скетч ESP32-S3 створює власну точку доступу.

Збережені слайдер, швидкість 1–100% (старт 50%), ручні Вліво/Вправо, центр, Маятник/Драбинка/Ривки/Рандом, серво45°/90° та STOP.
Коли мотор стоїть, зелений LED увімкнений. Під час фактичної подачі PWM зелений вимикається, а червоний працює як стробоскоп: 125 мс увімкнений і 125 мс вимкнений, тобто 4 повні спалахи за секунду. Після STOP знову світиться зелений.
При перезапуску зелений LED встановлюється увімкненим. Без енкодера прошивка визначає рух за ненульовим PWM: якщо мотор заблокований механічно, але драйвер отримує PWM, червоний все одно стробить; вільний вибіг після вимкнення PWM не визначається.
У скетчі ESP32-S3 серво запускається з програмою руху або кнопкою 45° чи 90°. Сервопривід отримує команду на відкриття й закриття кожні 2,5 с. «Стоп» зупиняє мотори, а цикл серво вимикається власною кнопкою «Вимк.». Для цього механізму 45° на сайті передається як команда 90°, а 90° — як команда 180°.
У config.h залишені попередні 333 Hz / 520–2520 мкс: перевірте відповідність паспорту вашого серво, не допускайте механічних упорів.

SPEED_CALIBRATION у config.h містить приклад, не виміри. Без енкодера координата розрахункова; після ручного руху заново виставляйте центр.
Жодна успішна компіляція не гарантує відсутність проблем живлення/пайки. Перший запуск — без силового живлення приводів, потім по одному компоненту.

Якщо кілька плат увімкнені поруч, змініть WIFI_SSID у кожній папці на різні назви — інакше важко зрозуміти, до якої ви під'єдналися.
